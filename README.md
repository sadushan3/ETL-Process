
# 🎯 DWBI Cube Project – Multidimensional Analysis

![DWBI Banner](https://img.shields.io/badge/SSAS-Cube_Project-blueviolet)  
📊 **University Coursework Submission | IT22180520 – S. Sadurshan**

This repository showcases a multidimensional cube project built using **SQL Server Analysis Services (SSAS)** as part of the **Data Warehousing and Business Intelligence (DWBI)** curriculum. The project is designed to analyze sales data using star schema modeling with rich cube browsing capabilities.

---

## 📂 Project Overview

The project focuses on modeling and analyzing data through a multidimensional approach. It contains:

- A complete SSAS cube project (`.sln` file)
- Dimension files (e.g., customers, products)
- A central fact table
- Hierarchies, measures, and calculated members

---

## 🧠 Features

✔️ Designed on **Star Schema**  
✔️ Includes **Customer**, **Product**, **Date** Dimensions  
✔️ Measures like `Total Sales`, `Quantity`, `Profit`  
✔️ Supports **Drill-down** & **Slice & Dice** functionality  
✔️ Deployable to **SSAS Multidimensional Model**

## 🧪 Getting Started

### 🔧 Prerequisites
- **Microsoft SQL Server Analysis Services**
- **Visual Studio with SQL Server Data Tools**
- **SQL Server Management Studio (SSMS)**

### 🚀 Steps to Run

```bash
# 1. Clone the repository
git clone https://github.com/yourusername/dwbi-cube-project.git

# 2. Open the .sln file in Visual Studio
MultidimensionalProjectAssigment.sln

# 3. Set up your data source (Data Source View)
# 4. Deploy and process the cube to your local SSAS server
# 5. Browse using SSMS or Excel Pivot
```
